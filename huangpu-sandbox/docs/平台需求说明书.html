1. 文档概述

1.1 建设背景

黄埔区城市更新项目群包含多个地块，采用 EPC 模式（费率下浮 5%），涉及市政集团、上海路桥等多方建设主体。项目全生命周期涵盖证照办理、设计出图、施工进度、成本测算、物资消耗、分包付款、现金流、风险管控、外协协调等业务。

当前各业务数据分散在 ES 经济管理系统、供应链平台、广联达算量、Jarvis BIM 进度展示、成本测算子系统等多个系统中。本平台以数字沙盘为统一展示与决策入口，通过数据同步汇聚各系统数据，实现「一屏总览、分层下钻、角色分权」。

1.2 建设目标

目标说明
多项目统筹四地块核心指标一屏展示，支持排名对比与预警
单项目穿透从总览下钻至证照、进度、形象、风险、成本、现金流等明细
业务系统协同成本、进度、物资、供应商、ES、现金流等子系统分工录入、沙盘只读汇聚
角色化视图指挥长只看沙盘；各部门只看与本职能相关的业务模块
数据不重复录入沙盘展示层禁止手工录入，数据来自接口/Excel/OCR 同步

1.3 适用范围

  • 在管项目：新联复建01地块（首期试点）、均一均二复建 AZ-01、洋田复建 AZ-01、均一均二复建 AZ-02
  • 合同模式：EPC（费率下浮 5%）
  • 用户组织：股份领导/指挥长、指挥部（商务部、工程技术部、外协部、财务部）

2.2 核心设计原则

三级数据流转

  • 录入层：ES、数字施工平台、供应链、广联达、成本测算子系统等为唯一录入源
  • 同步层：标准接口、Excel 导入、OCR，自动覆盖历史数据
  • 展示层：数字沙盘汇总 → 明细下钻 → 原始单据，禁止手动录入

可编辑 vs 只读

  • 蓝色输入框：业务人员可在子系统中编辑
  • 灰色只读字段：系统自动计算或沙盘汇聚展示
  • 沙盘嵌入的现金流等内容：只读看板，数据来自商务部测算

利润率业务规则

  • 业主给予总包固定利润：5%（EPC 费率下浮）
  • 项目目标利润率：16.66%（通过分包成本控制实现）
  • 实际利润率低于 16.66% 时触发预警，需分析工程量或材料单价偏差

4. 功能需求

4.1 用户认证

AUTH-02登录时选择角色，系统按角色加载导航与权限P0

Demo 阶段为模拟登录，正式版需对接企业统一身份认证。

4.2 数字沙盘 — 多项目总览看板

4.2.1 核心指标卡片

展示四地块汇总：在管地块数量、累计产值、风险总数、利润/物资预警项数。

4.2.2 四地块每周排名

维度：综合得分、进度完成、安全文明、成本管控、出图完成；支持导出 Excel/PDF。

4.2.3 图表分析

  • 各项目进度对比柱状图（滞后节点警告色）
  • 三值对比汇总：招标控制价 / 中标价 / 目标成本

4.2.4 四项目进度管控概览

Tab内容
证照办理进度四项目证照汇总表；指挥长只读
施工进度节点/专业、计划、实际、完成率、滞后状态
形象进度内部 Jarvis BIM iframe；外部航拍 AI 对比

4.2.5 动态现金流概览（只读嵌入）

5月实际/预测结余、预测偏差、6月预测；预测 vs 实际曲线；收入 vs 支出曲线；月度明细表；各项目5月现金流分项。标注「只读看板 · 数据来自商务部测算」。

4.2.6 项目列表卡片

名称、状态、EPC标的、产值、利润率、进度条、建设主体、风险、滞后节点；点击进入单项目详情。

4.3 数字沙盘 — 单项目详情

4.4 施工进度管控（工程技术部）

数据来源：Excel 导入 / Jarvis 进度展示（接口对接中）。含证照办理、施工进度（设计进度+里程碑+巡检）、形象进度三 Tab。支持 Excel 导入与导出报表。

4.5 风险管理系统（工程技术部）

四地块风险概览汇总表；分项目工程/经济/设计风险明细；支持导出风险汇总报表；可跳转单项目风险 Tab。

4.6 成本测算子系统（商务部）

表一：工程审核对比表

依据广联达造价表 + 施工深化图纸。含总表、单位工程（地下室/土石方/高层住宅）、分部分项清单、业主 vs 审核对比。审定量/价可编辑，自动重算核增核减。

表二：三算对比表

招标控制价 → 中标合同价 → 内部测算成本；对比实际成本/利润；低于 16.66% 红线预警。

表三：实际成本清单

专业分包、材料、中标清单三类台账。

4.7 物资消耗管控（商务部）

预算 vs 采购 vs 消耗对比；消耗超预算 10% 预警；数据来自供应链平台；消耗趋势图与预警报告导出。

4.8 供应商库（商务部/财务部）

材料供应商、施工工程供应商分类管理。字段：编号、名称、实控人、产品/范围、资质、投标/中标、联系方式、适用项目、入库状态。支持 Excel 导入与台账导出。数据来源：附件6《黄埔项目群分供商名录》。

4.9 ES 经济管理系统（商务部/财务部）

ES 为唯一录入源，沙盘禁止重复录入。模块：供应商管理、招标预审、合同评审、变更计量、资金支付、报账（OCR）。展示合同评审、变更计量、资金支付明细。

4.10 动态现金流（商务部/财务部）

测算假设：回款15工作日到账；分包进度款80%；材料月结30天；临界结余200万。含月度明细、预测vs实际曲线、收入vs支出、各项目分项、敏感性分析。子系统可编辑，沙盘嵌入只读。

4.11 外协协调（外协部）

类型：前期手续、党建联建、应急事件、外部协调。字段：编号、事项、项目、状态、负责人、截止日期。
