## 第 2 页｜建设背景

**核心信息：**

- 黄埔区城市更新项目群，多地块并行推进
- 合同模式：**EPC（费率下浮 5%）**
- 建设主体：市政集团、上海路桥等
- 业务链条长：证照 → 设计出图 → 施工 → 产值 → 成本 → 物资 → 付款 → 现金流 → 风险

**痛点：**

- 数据分散在供应链、广联达、Jarvis BIM、成本测算、文档归档等多个系统
- 领导难以「一屏掌握」，部门协同效率低
- 成本、进度、产值、现金流缺乏联动决策能力
- 合同/三会/设计资料缺乏统一归档与检索

## 第 5 页｜系统总体架构

**四层架构（自上而下）：**

```
展示层：数字沙盘（多项目总览 / 单项目详情 / 一体化决策推演）
录入层：成本测算 / 施工进度 / 设计管控 / 文档管理 / 工作管理
        / 风险 / 物资 / 供应商 / 现金流 / 外协协调

数据源：供应链 / 广联达 / Jarvis BIM / 成本测算子系统 / 文档库
```

**核心原则：** 录入在子系统 → 同步汇聚 → 沙盘只读展示

**三值对比：** 招标控制价 → 中标合同价 → 内部目标成本

## 第 12 页｜一体化决策推演（核心亮点）

**多因子联动推演：**

**6 大扰动因子：**

- 钢筋单价波动
- 关键节点延误
- 分包合同变更
- 业主回款延迟
- 混凝土用量偏差
- 质量整改投入

**5 个快捷情景：**

**输出：** 利润率变化 → 进度/质量/安全/现金流联动 → 雷达图 + AI 研判报告

## 第 13 页｜决策推演 — AI 研判

**推演流程：**

1. 选择项目 → 拖动滑块或输入自然语言情景
2. 即时计算：目标成本调整、利润率是否跌破 16.66% 红线
3. 生成 AI 一体化研判报告（流式输出）

**报告结构：**

- 综合研判 / 利润率影响（核心）
- 进度影响 / 质量与安全
- 现金流影响 / 成本分解
- AI 建议措施（商务部 48h 三算对比、钢筋集采议价等）

**演示话术：** 「如果钢筋涨 8% 且延误 30 天，利润率和 6 月现金流会怎样？」
